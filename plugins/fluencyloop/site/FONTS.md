# Bundled site fonts

The local site ships subsetted copies of these SIL Open Font License 1.1 typefaces:

- DM Sans, copyright Colophon Foundry
- Fraunces, copyright Undercase Type

The source files are from the Google Fonts project. They are subsetted to the character range the
site renders and served only from the bundled localhost server; no font request leaves the machine.
